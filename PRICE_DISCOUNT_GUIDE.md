# Price & Discount System Guide
*How ComeAway's pricing and discount system works for business users*

---

## What is This System?

The Price & Discount system enables ComeAway to:
- Set different prices for monthly, annual, and daily subscription plans
- Create promotional campaigns with specific names and offers
- Control which discounts appear with which pricing plans
- Track promotional campaign performance and usage

---

## How It Works

### Base Pricing Structure
- **Monthly Plan**: $9.99/month
- **Annual Plan**: $99.99/year  
- **Daily Plan**: $0.99/day

### Discount Campaigns
- **Named Promotions**: "July Special", "New User Discount", "Summer Sale"
- **Two Types**: Percentage (%) or Fixed Amount ($)
- **Time Limits**: Start date to end date
- **Usage Limits**: Maximum number of customers who can use each discount
- **Auto-Generated Codes**: System creates unique 8-character coupon codes automatically

### Discount Application Process
- Users enter auto-generated coupon codes to apply discounts
- System validates the coupon code and applies the discount
- Discounts are only applied when explicitly requested
- System tracks usage and prevents abuse

## How to Set Up Your Pricing and Discounts

### Step 1: Create Base Pricing
First, establish your base prices for each subscription plan:

```bash
POST /api/price/create
{
  "planType": "monthly",
  "basePrice": 9.99,
  "currency": "USD",
  "description": "Monthly Pro Plan"
}
```

**Note:** Features are optional. You can add features later or leave them empty.

### Step 2: Create Discount Campaigns
Next, create your promotional campaigns:

```bash
POST /api/discount/create
{
  "name": "Summer Sale 2024",
  "description": "Hot deals for hot weather!",
  "discountType": "percentage",
  "discountValue": 20,
  "startDate": "2024-06-01",
  "endDate": "2024-08-31",
  "usageLimit": 1000
}
```

**Note:** The coupon code will be automatically generated by the system (e.g., "A7B2K9X1"). You don't need to include it in the request body.

### Step 3: Assign Discounts to Specific Prices
This is the key step that gives you control over which discounts appear with which prices:

```bash
POST /api/price-discount-assignments/assign
{
  "priceId": "689fab792f4e203b9cd35a2f",
  "discountId": "689fa2e301754777fbdfb938"
}
```

**Important:** Only assigned discounts will appear in the price endpoint responses. This gives you precise control over your promotional strategy.

### Step 4: Test Your System
Verify that everything is working correctly:

```bash
# Get price with available discounts
GET /api/price/plan/monthly/with-available-discounts

# Apply discount manually
POST /api/price/apply-discount
{
  "planType": "monthly",
  "couponCode": "A7B2K9X1"
}
```

## System Architecture

### Price-Discount Assignment System
The system uses an assignment-based approach where discounts must be explicitly assigned to prices:
- **No Automatic Display**: Discounts won't show up in price endpoints unless assigned
- **Explicit Control**: Business users decide which discounts appear with which prices
- **Flexible Management**: Easy to add/remove discounts from prices
- **Better Organization**: Clear separation between available discounts and price-specific offers

### Coupon Code Auto-Generation
The system automatically generates unique 8-character coupon codes for each discount:
- **Format**: 8 characters (A-Z, 0-9)
- **Examples**: "A7B2K9X1", "K9M3P8Q2", "X5N1R7T4"
- **Uniqueness**: Each code is guaranteed to be unique across all discounts
- **No Manual Input**: Business users don't need to create or manage coupon codes

**Important:** 
- **Creating Discounts**: Don't include couponCode in request body (auto-generated)
- **Applying Discounts**: Users must provide the couponCode to use the discount

### Date-Only Format
All dates use date-only format (no time component):
- **Format**: YYYY-MM-DD (e.g., "2025-08-15")
- **No Time**: Start and end dates are set to the beginning of the day
- **Simple**: Easier to manage and understand
- **Consistent**: All date comparisons use the same format

## API Endpoints

### For Business Users (Public)
- `GET /api/price/all` - View all plan prices
- `GET /api/price/plan/monthly/with-available-discounts` - View monthly price with assigned discounts only
- `POST /api/price/apply-discount` - Apply discount using coupon code
- `GET /api/discount/active` - View current active discounts

### For Administrators (Protected)
- `POST /api/price/create` - Create new pricing
- `POST /api/discount/create` - Create new discount campaign
- `PUT /api/discount/:id` - Update discount details
- `DELETE /api/discount/:id` - End discount campaign
- `POST /api/price-discount-assignments/assign` - Assign discount to specific price
- `PUT /api/price-discount-assignments/remove/:priceId/:discountId` - Remove discount from price

## Best Practices

### Do's
- **Clear Names**: Use descriptive names like "Black Friday Special"
- **Reasonable Limits**: Set usage limits based on your business capacity
- **Test First**: Always test discounts before going live
- **Monitor Usage**: Track how many customers use each discount
- **Strategic Assignment**: Only assign discounts to plans where they make business sense

### Don'ts
- **Overlap Campaigns**: Avoid multiple discounts for same plans
- **Extreme Discounts**: Don't go below 50% off (hurts revenue)
- **Forget Expiry**: Always set end dates for campaigns
- **Ignore Analytics**: Track which discounts work best for your business
